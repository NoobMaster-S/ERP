# Object Storage Architecture Specification

## 1. Storage Principles

1. **No Binary Blobs in PostgreSQL**: Database stores strictly file metadata (`storage_key`, `filename`, `content_type`, `size_bytes`, `business_id`, `uploaded_by`, `created_at`).
2. **S3-Compatible Abstraction (`StorageService`)**:
   Enables zero-friction portability between:
   * AWS S3
   * Cloudflare R2 (zero egress fees)
   * MinIO (local self-hosted development & testing)
   * Supabase Storage / DigitalOcean Spaces
3. **Multi-Tenant Path Isolation**:
   All uploaded keys follow strict tenant prefixing:
   `tenants/{business_id}/{category}/{year}/{month}/{uuid}_{filename}`
4. **Presigned Upload & Download URLs**:
   Large uploads stream directly from the client to the S3 bucket using short-lived (15-minute) presigned PUT URLs generated by Django, eliminating backend memory and bandwidth bottlenecks.

---

## 2. Storage Service Interface

```python
class StorageService(ABC):
    @abstractmethod
    def generate_presigned_upload_url(
        self, business_id: str, file_category: str, filename: str, content_type: str, max_size_bytes: int = 10_000_000
    ) -> PresignedUploadPayload:
        """Returns signed URL and storage_key for direct client-to-storage uploads."""
        pass

    @abstractmethod
    def generate_presigned_download_url(
        self, storage_key: str, expires_in_seconds: int = 900
    ) -> str:
        """Generates signed read URL."""
        pass

    @abstractmethod
    def delete_object(self, storage_key: str) -> bool:
        """Deletes object from storage."""
        pass
```
